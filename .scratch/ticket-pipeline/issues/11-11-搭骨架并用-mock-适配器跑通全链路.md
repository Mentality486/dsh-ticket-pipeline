**要交付的**：

2. **四层接口与内核**：`src/core/{scheduler,store,config}.js` + `src/contracts/*.d.ts`（或 `.ts`，看工具链定）。
3. **四个 Mock 实现**：`MockTicketSource`（返回 2 条假工单）、`MockRepoLocator`（返回固定路径）、`MockWorkExecutor`（伪造 `ExecResult`，含一次 `failed` 场景）、`MockPushAdapter`（打日志）。

6. **可跑通验证**：能实跑一遍、看到日志按 `pending → worktree-ready → planning → editing → testing → mr-opening → done` 走完，且 `failed` 场景能正确发 mock 通知。

**关键约束**（来自 #05）：

- agent 走**进程内** `ctx.agents.create()`，不用 `dsh --profile headless` 子进程。

- 超时用 `ctx.timer.timeout` 包整票 → `agent.cancel()` + 标 `failed` + 保留 worktree。
- **不要**围绕 `webhookRuntime` 做设计（这个 build 里它没有 provider）。
- 安装只能用 `plugin_manager install_bundle`，禁止手改 profile manifest。
